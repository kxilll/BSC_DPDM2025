# 📖 Chapter 1: Introduction to Data Mining

## 🔥 Why Data Mining?
โลกในปัจจุบันมีข้อมูลเพิ่มขึ้นอย่างต่อเนื่อง  
แต่ข้อมูลจะไม่มีความหมายเลย หากไม่สามารถนำมาวิเคราะห์ได้  

Data Mining จึงมีบทบาทในการ:
- 🔍 ค้นหา insight ที่ซ่อนอยู่  
- 📊 วิเคราะห์พฤติกรรม  
- 📈 ทำนายแนวโน้มในอนาคต  
- 🎯 สนับสนุนการตัดสินใจ  

---

## 🔍 What is Data Mining?
Data Mining คือกระบวนการค้นหารูปแบบ (patterns)  
และความรู้จากข้อมูลขนาดใหญ่  

โดยอาศัย:
- Machine Learning  
- Statistics  
- Algorithms

## 📊 Real-World Example

Example: Food Delivery Recommendation System

- Input: user behavior (time, order history, preferences)  
- Process: clustering + classification  
- Output: recommended restaurant  

👉 Result:

- เพิ่ม user engagement

## 🧾 Summary

Data Mining คือการเปลี่ยน  
**Data → Insight → Decision**

✔ ใช้ Machine Learning และสถิติ

## 🚀 Key Takeaways

- Data Mining ≠ การดูข้อมูล แต่คือ “การสร้างการตัดสินใจ”  
- Value อยู่ที่ “Insight ไม่ใช่ Data”  
- เป็นหัวใจของ AI และ Business Analytics
